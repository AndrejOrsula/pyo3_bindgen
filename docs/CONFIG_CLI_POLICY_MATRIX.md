# Configuration, CLI, Macro, and Consumer Policy Matrix

This is the indexed policy source for the public `Config` fields, the CLI, the
procedural macro, names that generated code requires from its consumer, and
workspace-internal controls that are published but unsupported for consumers.
Each row has one control and one exact behavior statement. `Source-mode applicability` is `live`, `external-ir`, `both`, or `n/a`; `none` is an
explicit empty conflict or dependency entry.
